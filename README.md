 # 多格式引用生成器 (Multi-format Citation Generator)

一个简洁、高效、纯前端的 Web 应用，旨在帮助学者、学生和研究人员快速、准确地生成多种主流格式的文献引用。

[**» 前往使用 (Live Demo) «**](https://15236702150master.github.io/reference_citations/)

---

## ✨ 项目特色 (Features)

*   **多种引用格式**: 支持三种最主流的学术引用格式：
    *   APA 7th Edition
    *   MLA 9th Edition
    *   Chicago 17th Edition (Author-Date)
*   **批量处理**: 支持一次性输入多个文献标题（每行一个），即刻批量生成所有引用。
*   **历史记录**: 自动在浏览器本地保存您的生成历史，方便随时回顾和复制，关闭页面不丢失。
*   **纯前端实现**: 所有操作都在您的浏览器中完成，无需服务器，确保了极快的响应速度和用户数据的绝对隐私。
*   **现代设计**: 界面干净、直观，专注于核心功能，提供流畅的用户体验。

## 🚀 如何使用 (How to Use)

1.  **访问应用**: 打开 [在线演示地址](https://15236702150master.github.io/reference_citations/).
2.  **输入标题**: 在“生成器”视图的文本框中，粘贴一个或多个文献的完整标题，请确保每行只有一个标题。
3.  **选择格式**: 从下拉菜单中选择您需要的引用格式 (APA, MLA, 或 Chicago)。
4.  **生成引用**: 点击“生成引用”按钮。应用将开始处理您的请求。
5.  **查看结果**: 生成的引用会立即显示在按钮下方。您可以轻松地点击“复制”按钮来复制代码，或使用“一键复制所有”来获取全部结果。
6.  **查看历史**: 点击导航栏的“历史记录”按钮，可以查看您之前生成过的所有引用。

## ⚠️ 注意事项与问题排查

本项目致力于提供便捷的工具，但由于一些外部依赖和环境因素，您在使用中可能会遇到问题。

### **最常见问题：生成失败或长时间无响应**

*   **原因**: 本应用的引用格式化功能可能依赖于一个部署在**国外服务器**上的开源 API 服务。在中国大陆地区，由于网络环境的复杂性（如 GFW），您的浏览器可能无法稳定地连接到该服务器，这是导致生成失败或无响应的**最主要原因**。
*   **解决方案**:
    1.  **检查网络环境**: 尝试使用科学上网工具（VPN 或代理）后刷新页面重试。这通常能解决绝大多数问题。
    2.  **检查输入内容**: 确保您输入的文献标题是准确、完整的，错误的标题可能导致 API 无法识别。
    3.  **服务可用性**: 极少数情况下，可能是远程 API 服务器暂时宕机或维护。您可以稍后再试。

### **其他注意事项**

*   **数据隐私**: 所有输入和历史记录都存储在您自己的浏览器本地存储（LocalStorage）中，不会上传到任何服务器，请放心使用。
*   **引用准确性**: 本工具生成的引用绝大多数情况下是准确的，但请务必在使用前根据您的具体要求进行二次核对。
